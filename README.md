# Ковка для Android

Ковка находит открытые приложения на GitHub, скачивает исходники конкретного коммита и собирает APK на телефоне. В каталоге есть подборка популярных проектов, поиск по названию и переход по ссылке на репозиторий.

1. Установите [Ковку](https://github.com/Artemnuhka/kovka/releases/download/v1.1.0/Kovka-1.1.0.apk) на 64-битное устройство с Android 9 или новее.
2. Откройте проект и нажмите **Собрать APK**. При первой сборке Ковка сама загрузит инструменты.
3. Нажмите **Логи** на карточке проекта или во вкладке **Сборки**, чтобы увидеть ход работы.
4. Нажмите **Установить** у готового APK и подтвердите действие в Android. Результат установки появится в том же журнале.

Сборщик поддерживает Android Gradle и умеет подготовить Flutter, React Native, Expo и Capacitor. Совместимость зависит от версии проекта, его зависимостей и инструментов для архитектуры телефона. Для монорепозитория можно указать подпапку и задачу Gradle. Собирайте проекты, которым доверяете, поскольку при сборке выполняется их код.

## Сборка приложения

Ковка написана на Kotlin и использует Jetpack Compose с Material 3 Expressive. Сборка приложения требует JDK 27 и Android SDK 37.

```sh
./gradlew :app:assembleRelease :app:lintRelease
```
