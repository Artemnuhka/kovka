# Ковка для Android

Ковка ищет открытые Android-проекты на GitHub и собирает APK из конкретного коммита на самом телефоне. В приложении есть каталог, журнал сборки и история APK с установкой через системный диалог Android. Интерфейс сделан на Jetpack Compose с компонентами Material 3 Expressive.

## Установка и первая сборка

1. Установите [Ковку](https://github.com/Artemnuhka/kovka/releases/download/v1.0.0/Kovka-1.0.0.apk) и [Termux из F-Droid](https://f-droid.org/packages/com.termux/). Откройте Termux один раз.
2. В Ковке, на вкладке **Среда**, скопируйте команду настройки, выполните её в Termux и выдайте Ковке разрешение на запуск команд Termux.
3. Нажмите **Подготовить среду** и подтвердите условия Android SDK. Инструменты и кэш сборок хранятся в каталоге `~/.kovka` внутри Termux.
4. Найдите проект по названию или вставьте ссылку на GitHub. Откройте проект и нажмите **Собрать APK**.
5. После сборки откройте вкладку **Сборки** и выберите **Установить**. При первой установке Android запросит разрешение для Ковки.

В каталоге отображаются репозитории с открытой лицензией, которую GitHub распознаёт по SPDX. Ковка фиксирует SHA коммита перед запуском, скачивает этот коммит через Git и передаёт проект локальному Gradle. Нужен интернет для GitHub и загрузки инструментов и зависимостей.

## Совместимость

- Ковка поддерживает Android 8.0 и новее. Для сборки нужен Termux с актуальными пакетами JDK для архитектуры устройства.
- Поддерживаются проекты Android с Gradle Wrapper от 7.3 и выше. По умолчанию запускается `assembleDebug`. В параметрах проекта можно указать подпапку, конкретную задачу Gradle и JDK.
- Termux использует OpenJDK 25.0.5.1, 21.0.13.1 или 17.0.21.1 и более свежие обновления этих веток в зависимости от Gradle. Для инструментов на телефоне нужна первая настройка и место под кэш.
- Для установки нужен подписанный самостоятельный APK. Проекты, которым требуются NDK, Flutter SDK, внешние ключи, секреты сборки или наборы split APK, потребуют собственной настройки или могут оказаться несовместимыми.
- Gradle запускает код проекта с правами Termux. Проверяйте исходники и доступы Termux перед запуском сборки.

## Сборка самой Ковки

Проект собирается на Gradle 9.9.1, JDK 27 и Android SDK 37. Релиз 1.0.0 собран на Eclipse Temurin 27.0.1.1+4. Java 17 в Gradle DSL определяет формат байткода для Android.

```sh
./gradlew :app:assembleRelease :app:lintRelease
```

Установочный релиз подписан локальным ключом из закрытого каталога `.release-signing/`. Для обновления этой установки нужно подписать новую версию тем же ключом.
